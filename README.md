# Justin L. Gabis — Portfolio

A responsive personal portfolio starter personalized from the information in Justin L. Gabis's uploaded résumé and the uploaded professional portrait. It takes inspiration from the Brewed Ops portfolio template's dark editorial aesthetic, profile-led layout, and 3D showcase concept; this is a separately prepared starter project, not a direct fork of the original repository.

## Included
- Responsive homepage, about section, experience timeline, education, leadership, skills, and contact area
- Profile portrait and résumé PDF in `assets/`
- CSS 3D-style carousel with placeholder cards for projects, funnels, and websites
- Reduced-motion support and mobile layout

## Run locally
No build tools or package installation required. Open `index.html` in a browser, or serve the folder with any static web server.

## Publish to your own GitHub repository
1. Create a new repository under your own GitHub account (for example, `justin-gabis-portfolio`).
2. Upload the contents of this folder to that repository.
3. In the repository, open **Settings → Pages** and configure deployment from the `main` branch and root folder.
4. Once GitHub Pages finishes publishing, use the site URL shown in the Pages settings.

## Add your future work
The showcase cards are currently placeholders on purpose. Edit the three `.work-card` elements in `index.html` to add a project name, type, summary, preview image, and project URL. You can add more cards and matching carousel dots as your portfolio grows.

## Content notes
The content is based on the uploaded résumé. No unprovided social links, client projects, campaign results, or certifications have been invented. The original résumé includes personal contact details; review them before making this repository public.
